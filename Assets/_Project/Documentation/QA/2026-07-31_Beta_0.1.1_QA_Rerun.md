## Final Choice Regression

Runtime order was traced from `GameManager.HandleSquadDefeated` to `RunStatsTracker.EndRun`, `SaveService.RecordRunResult`, snapshot creation, and then `StoryCutsceneRuntimeController.TryPlayPostRunCutscene`. `totalRunsCompleted` is incremented exactly once before story eligibility is evaluated, so the run that changes the value from 49 to 50 is eligible.

The Final Choice rule now requires all of the following:

- `totalRunsCompleted >= 50` with no upper limit;
- current run survival time `>= 420` seconds;
- `CS_06_SystemFatigue` has been seen;
- `CS_07_FinalChoice_PreChoice` has not been seen.

Coverage includes runs 49, 50, 51, and 100; survival just below and exactly at 420 seconds; missing System Fatigue; an already-seen Final Choice; and save compatibility above run 50. The mission regression confirms `Final Choice -> break_final_choice -> TERMINAL PROTOCOL`, while later Terminal missions remain locked until their own prerequisite is complete.
